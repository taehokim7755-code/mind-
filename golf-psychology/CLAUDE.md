## 새 영상 만들 때 (EP.01에서 정한 방식, 매 편 그대로)
1. `build.py init` 직후: `채널_style.css`를 작업 폴더 `style.css`로 덮어쓴다 (브랜드 색 + 옅은 막). `config.json`에 voice·channel·slogan·stock_lib(`D:/유남매 작업실/골프심리학/스톡`) 넣기
2. 대본: 레퍼런스 보고서 + 피드백 기록대로. 첫 1~2문장에 가장 센 실제 연구 역설
3. 화면 소재: 실사 스톡 절반 이상 + AI 그림(웹툰풍, 주인공 고정)은 이야기 장면만. 소재 60개 이상, 재사용 3회 이하
   - 실사: `스톡/픽사베이`(골프) · `스톡/자료`(뇌과학·실험실·자연). 부족하면 픽사베이에서 더 받기(받기 전 목록 보여주고 허락)
   - AI 그림: 프롬프트 형식은 `이미지프롬프트_웹툰_EP01.txt`. 사용자가 Flow에서 만들어 `스톡/이미지/`에 저장 → 워터마크 모서리 잘라 10초 클립(`스톡/클립/`)
4. plan.py: 문장 구간 → 그룹(GROUPS·SCENE 방식, EP.01 `round7/plan.py` 참고). 카드 비율 60~70%. 단계 표지 chip은 "STAGE n"만(숫자 섞이면 큰 숫자 깨짐)
5. 렌더 뒤: qc.py · verify.py PASS + 검수시트 전부 눈 확인 + /영상보기로 0초·빈 카드·소재 일치 점검
